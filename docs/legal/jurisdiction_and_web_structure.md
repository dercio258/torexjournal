# Jurisdição e Estrutura do Website - Torex Journal

## 6. Modelo de Jurisdição Flexível
Para garantir a operabilidade global do **Torex Journal**, os documentos foram redigidos de forma neutra, permitindo adaptações rápidas:

*   **Opção A (EUA/Internacional):** Aplicar leis do Estado de Delaware ou localidade similar, com ênfase em arbitragem comercial.
*   **Opção B (Europa/GDPR):** Focar na proteção de dados e direitos do consumidor da UE conforme estabelecido na nossa Política de Privacidade.
*   **Opção C (Brasil/LGPD):** Adaptar as cláusulas de faturamento para as normas do Código de Defesa do Consumidor e garantir armazenamento de logs conforme Marco Civil da Internet.
*   **Opção D (Offshore):** Para usuários em jurisdições de baixa regulação, manter a cláusula de isenção de responsabilidade técnica como ponto central.

## 7. Estrutura de Páginas Recomendada para o Website

Para uma publicação profissional e de fácil navegação (SEO e UX), organize os conteúdos nas seguintes rotas:

### 📄 Página [/terms](file:///terms)
*   **Conteúdo:** `terms_and_conditions.md`
*   **Ação:** Deve exigir aceitação (checkbox) no momento do cadastro.

### 📄 Página [/privacy](file:///privacy)
*   **Conteúdo:** `privacy_policy.md`
*   **Ação:** Incluir link no rodapé e banner de cookies.

### 📄 Página [/risk-disclosure](file:///risk-disclosure)
*   **Conteúdo:** `risk_disclosure.md` (Seção 4)
*   **Ação:** Link obrigatório no rodapé de todas as páginas da plataforma.

### 📄 Página [/legal](file:///legal)
*   **Conteúdo:** Hub central com links para Termos, Privacidade e Disclaimers. Inclui o **Disclaimer Profissional** (Seção 5).

### 📄 Página [/documentation](file:///documentation)
*   **Conteúdo:** `documentation.md`
*   **Ação:** Versão pública simplificada para suporte e guias de integração API.
