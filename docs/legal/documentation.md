# Torex Journal - Platform Documentation

## 1.1 Visão Geral do Produto
O **Torex Journal** é uma plataforma SaaS (Software as a Service) de ponta projetada para traders profissionais e institucionais. Nossa missão é transformar dados brutos de trading em inteligência acionável, permitindo que os usuários identifiquem padrões, otimizem estratégias e eliminem falhas comportamentais. 

**Nota Crucial:** O Torex Journal é uma ferramenta exclusivamente analítica e educacional. Não somos uma corretora, não custodiamos ativos e não executamos ordens de compra ou venda.

## 1.2 Funcionalidades Principais
*   **Análise Avançada de Trades:** Processamento de métricas complexas em tempo real.
*   **Gestão de Desempenho:** Dashboard interativo com visualização de PnL, Drawdown, e Win-Rate.
*   **Backtesting (Manual e Automatizado):** Ambiente de simulação para validação de estratégias sobre dados históricos.
*   **Diário de Trading (Journal):** Espaço para registro de setups, capturas de tela e notas psicológicas.
*   **Estatísticas Avançadas:** Expectancy, Razão R:R, Fator de Lucro, Índice de Sharpe e mais.
*   **Análise Comportamental:** Rastreamento de "mood" e padrões emocionais correlacionados ao desempenho.
*   **Gestão Multi-Trader:** Estrutura para equipes ou gestores de contas (PAMM/MAM logic visualization).

## 1.3 Estrutura de Conta
*   **Plano Individual:** Para traders autônomos que buscam alta performance.
*   **Plano Institucional/Equipe:** Painel administrativo para gestão de múltiplos usuários, relatórios consolidados e controle de acesso hierárquico.

## 1.4 Planos e Assinaturas
*   **Mensal:** Acesso completo com renovação automática a cada 30 dias.
*   **Anual:** Desconto promocional para compromisso de longo prazo, faturado anualmente.
*   *Nota: O acesso é interrompido imediatamente após o término do período de faturamento caso não haja renovação.*

## 1.5 Integrações
Oferecemos importação automatizada via chaves de API e sincronização direta para:
*   MetaTrader 4 (MT4) e MetaTrader 5 (MT5).
*   cTrader.
*   Exchanges de Criptoativos (Binance, Bybit, etc.).
*   Importação via arquivo (CSV/Excel) para plataformas legadas.

## 1.6 Sistema de Backtesting
O motor de backtesting do Torex Journal utiliza dados de mercado históricos de alta fidelidade para permitir que o trader valide sua vantagem estatística sem risco de capital real. Suporta múltiplos ativos e cronogramas customizáveis.

## 1.7 Segurança de Dados
*   **Criptografia:** Dados em repouso (AES-256) e em trânsito (TLS 1.3).
*   **Isolamento:** Esquema de banco de dados isolado para garantir que os dados de trading de um usuário nunca se misturem com outros.
*   **API Segura:** Armazenamento criptografado de chaves de API com permissões de "Somente Leitura" exigidas.

## 1.8 Limitações de Responsabilidade
O Torex Journal fornece cálculos matemáticos baseados em dados importados. Não nos responsabilizamos por:
*   Inexatidão nos dados fornecidos pelas corretoras.
*   Falhas de conectividade de terceiros.
*   Decisões financeiras baseadas nas estatísticas da plataforma.

## 1.9 Suporte e SLA
*   **Disponibilidade (Uptime):** Meta de 99.9% anual.
*   **Suporte:** Atendimento em níveis (N1, N2) via ticket e e-mail com resposta em até 24h úteis para assinantes Premium.

## 1.10 Cancelamento e Reembolso
*   **Cancelamento:** A qualquer momento via painel de controle.
*   **Reembolso:** Política de 7 dias (ou conforme legislação local aplicável) para novos assinantes que não tenham realizado importações massivas de dados.
